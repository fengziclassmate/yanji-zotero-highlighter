# 研迹 · Zotero 网页标注 v0.8.2

Edge Manifest V3 本地扩展，无构建步骤和第三方运行时依赖。Edge 打开 edge://extensions/，启用开发人员模式，加载此文件夹；打开 Zotero 10 并启用设置中的本地通信，再刷新文章页。完整配置说明见仓库根目录 README.md 或安装包的“安装说明.html”。

## 功能

- 参考文献、推荐文章和 Cited by 标题分别勾选翻译，保留英文并添加中文。按阅读位置翻译，缓存复用；支持小牛、Google 免 Key、微软 Edge 免 Key、Google Cloud 和微软 Azure。API Key 仅本机保存，不进入配置或备份。
- 九类颜色色签显示数量，点击筛选、再次点击恢复全部；网页高亮与侧栏卡片联动。
- 九类默认颜色；可修改分类名称、含义、颜色与顺序。
- 中文划线、批注、段落回跳，适配沉浸式翻译双语正文。
- 本地规则根据句序、长度、数字及缩写预选英文候选，保留已有确认结果；点击保存后确认一对一或一对多英文，保存后显示英文高亮并写入分类笔记，不联网、不加载模型。
- 文章摘要索引、父文献定向读取、每页 50 条展示；首次升级按批次建立索引，保留原标注和授权。
- 备份按批读取、导入按 2 MiB 字符块传送，兼容现有 JSON 备份。
- 笔记只写中文摘录、批注、已确认英文句对和手写总结，不再附加完整原文段落。20 万 HTML 字符安全预算，超长时停止写入并保留本地数据。
- 偏好页按窗口可用宽度自适应，宽屏分组并排，窄屏上下排列，背景覆盖完整窗口。
- 侧栏与偏好设置支持 Ctrl + 滚轮缩放，分别在本机记忆；默认 110%。点击比例或 Ctrl + 0 恢复 100%。
- 划线样式右侧按默认分类颜色实时预览。
- 透明浮窗、全部分类展开、图标按钮和拖动尺寸记忆。
- 未入库时本地缓存；打开网页或更新笔记时按 DOI 精确关联；多篇候选由用户选择。
- 已授权时打开网页自动更新同一份分类子笔记，可在偏好中关闭。不轮询文献库。
- 手写总结保留、摘录区与版本冲突检查；同一文献的多个网页合并到同一笔记。
- 共享配置导入、导出；个人数据备份、恢复与 Markdown 导出。

## 数据

标注保存在当前 Edge 配置；标注同步请求发往本机 Zotero 10；开启参考文献翻译后，标题还会发往自行选择的翻译服务。写入授权由 Zotero 提供，各使用者分别授权。共享配置不含标注、文献关联或授权；个人完整备份含标注与文献关联，不含授权密钥。写入后的笔记由 Zotero 账号同步。完整备份不含本地索引和笔记覆盖基线；导入已有 Zotero 文献后，首次更新可能需要确认重建摘录区。

## 范围

顶层 HTML 正文和“我的文献库”。尚未支持图片、内置 PDF 阅读器、群组文献库和高亮定位数据的多设备自动同步。PDF 导入后需识别为父文献并具有与网页相同的 DOI；缺失时可手动关联。

更新时保持安装路径不变，覆盖文件后在 Edge 扩展管理页重新加载并刷新文章。卸载前请导出完整备份。

## v0.3.2

句对只追加去重后的英文，中文不重复；已对齐片段不附加整段英文。侧栏只展开对应英文，完整段落共用按需查看窗。“我的总结”移除括号，兼容旧标题并保留手写内容。

## 标题复制

侧栏标题右下角直接提供复制和文件夹两个纯图标按钮，无需菜单；“完整标题”原样复制全部标题，“文件夹名称”将 Windows 禁用字符 `\ / : * ? " < > |` 与控制字符替换为空格，合并空白、清除结尾的句点与空格。保留中文全角标点；遇到 CON、NUL 等保留名时添加下划线前缀，空名称改为“未命名”。不自动截断长标题；实际长度仍受 Windows 和存放路径限制。

## Zotero PDF 高亮

在 Zotero 10 安装本仓库 dist/ 中的研迹配套 XPI。网页中文先保存英文句对，关联文献并导入 PDF 后，点击侧栏“PDF 标注”定位并确认写入。颜色沿用分类，中文与批注写入高亮评论。重复操作沿用同源标注，Zotero 中手动改动的标注会跳过。当前不做中文到英文的自动语义匹配或 OCR；网页摘录删除后不会自动删除 PDF 高亮。详细配置和适用范围见仓库根 README。

## v0.8.0 阅读交互

- 颜色色签：按现有分类顺序显示，悬停看名称、含义和数量，点击筛选，再点取消。
- 双向联动：侧栏打开时点击网页高亮，会定位并强调对应卡片；卡片的定位图标回到网页段落。
- 双语复制：点击复制摘录，Shift + 点击附加已确认英文句对和个人批注，不复制整段未选原文。
- 删除撤销：删除后 8 秒内可撤销最近一次删除，恢复原标注 ID、分类、句对和批注。
- 来源返回：今后从 ScienceDirect 点击 Scopus 链接后，Scopus 侧栏出现返回箭头，回到来源文章与阅读位置；来源页已关闭时重新打开。
- 稍后读：推荐、被引和 Scopus 标题旁悬停出现书签。保存后图标常显，在侧栏“稍后读”打开或移出；不自动导入 Zotero。
- 长摘录折叠：超过四行时显示展开/收起图标，复制与同步始终保留全文。
- 继续阅读：学术正文或已有研迹标注的网页，用户滚动停下后记录位置；再次访问时出现继续阅读图标，由用户决定是否跳转。Scopus 结果列表不记录正文断点。

稍后读和阅读位置随个人完整 JSON 备份导入、导出，兼容旧备份。来源关系和短时撤销只在当前浏览器会话中保留，不导出。网页结构变化、位置不能唯一匹配时，阅读断点会返回接近的位置并提示。删除和撤销标为待更新，更新后仍沿用对应文献的同一份笔记；不会自动删除已写入的 PDF 高亮。
