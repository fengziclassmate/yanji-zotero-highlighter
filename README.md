# 研迹 · Zotero 网页标注

在 Edge 网页正文中标注中文译文，用自己的颜色分类阅读内容，再更新到 Zotero 10 对应文献的一份笔记中。

**当前版本：0.8.1。** 原生 Manifest V3 扩展，无构建步骤、第三方运行时依赖或自建服务器。网页标注和分类笔记无需额外的 Zotero 插件；要在 Zotero PDF 中显示原生高亮，安装下方的配套插件。无需填写 Zotero 账号密码或手动申请 Zotero API Key。

## 安装到 Edge

1. 在本仓库点击 **Code → Download ZIP**，完整解压到固定位置。
2. Edge 地址栏输入 `edge://extensions/`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择仓库中的 **`yanji-edge` 文件夹**，该文件夹内应有 `manifest.json`。
4. 将“研迹”固定到工具栏，刷新已经打开的文章页，点击图标打开侧栏。
5. 打开 Zotero 10，在“设置 → 高级”中启用“允许此计算机上的其他应用程序与 Zotero 通信”，并保持 Zotero 运行。

本地 HTML 需要在扩展详情中开启“允许访问文件 URL”。普通期刊网页不需要这一步。

**升级：**先在研迹“配置与备份”导出个人完整备份，再覆盖原安装位置中的文件。在 Edge 扩展管理页点击研迹的“重新加载”，最后刷新文章页。保持安装路径不变，避免卸载后重新安装造成数据丢失。

## 阅读与标注

1. 在期刊的 HTML 正文中阅读，可先用沉浸式翻译显示中英双语。
2. 选中中文或英文，点击浮窗中的颜色分类保存。气泡图标添加批注，叠页图标复制，右上角 × 关闭。
3. 点击已有划线可编辑分类和批注；`Ctrl / Cmd + Enter` 保存。
4. 侧栏显示摘录、分类和批注。标题右下角有两个纯图标按钮，分别用复制图标复制完整标题、文件夹图标复制安全文件夹名；悬停可查看提示；后者将 Windows 禁用字符 `\ / : * ? " < > |` 与控制字符替换为空格，合并空白、去掉结尾的句点和空格，保留中文全角标点。CON、NUL 等系统保留名会添加 `_` 前缀，空名称使用“未命名”。不自动截断长标题，实际长度仍受系统和所在路径限制。DOI 旁和摘录右下角的按钮各自复制相应内容。定位按钮返回网页段落。
5. 未做句对时，“原文段落”按需打开共用查看窗；做了句对后，卡片只展开对应英文，不再重复铺开长段落。“完整段落”仍可查看定位原文。

批注浮窗可拖动标题栏调整位置，并在本机记忆；分类直接点击颜色标签选择。批注输入框默认更紧凑，可继续手动拉高。浮窗支持拖动右下角调整大小并记忆。背景透明度、按钮大小、全部分类展开、快捷键和默认标注方式可在偏好设置中调整。侧栏和偏好设置分别支持 `Ctrl + 滚轮` 缩放并记忆；点击比例或按 `Ctrl + 0` 恢复 100%。偏好页根据窗口可用宽度重新布局。

## 文献标题翻译

1. 点击研迹右上角偏好设置，打开独立设置弹窗，选择 **翻译**。重复点击会聚焦已有窗口，不新增标签页。拖动调整窗口大小或位置会自动在本机记忆，下次打开恢复；换到较小屏幕时保持在当前屏幕可见范围内。
2. 选择翻译服务，填写自己的 API Key；Azure 区域按资源所在地填写，全球资源可留空。各服务的配置分别在本机保留。
3. 点击 **测试翻译**，按浏览器提示允许访问该服务；成功后在文章侧栏按需勾选 **参考文献翻译**、**推荐文章**、**Cited by**，三项并列显示，独立控制。
4. 滚动到相应区域，研迹保留原始英文，为已勾选类别添加中文标题。作者、期刊、年份、DOI 和其他插件的标签保留。推荐文章和 Cited by 支持 ScienceDirect 卡片；从被引区域跳转到 Scopus 文献结果列表后，继续沿用 **Cited by** 勾选项。网站未加载的文章和未打开的结果页不会主动请求加载。
5. 取消某一项，只移除该类别的研迹译文并停止它的后续请求；其他已勾选类别保留。重新勾选优先使用已有缓存，同一标题跨类别共用缓存。

| 服务 | 配置 |
| --- | --- |
| 小牛翻译 | 自己的小牛 API Key，调用官方文本翻译 API |
| Google 翻译（免 Key，实验） | 无需 Key，使用网页接口；依赖网络可达性，可能限流或失效 |
| 微软 Edge（免 Key，实验） | 无需 Key，使用网页接口；可能限流或失效 |
| Google Cloud | 自己的 Cloud Translation Basic v2 API Key |
| 微软 Azure | 自己的 Translator Key 和区域；支持免费层，额度以服务商规则为准 |

新安装时三项默认关闭；升级时保留原参考文献开关，新两项默认关闭，选择状态在本机记忆。只发送识别出的标题，不发送整篇正文、作者列表或 Zotero 文献库。标题进入阅读区域附近时才请求翻译，切到后台后暂停新任务；全局串行发送，间隔至少 600ms。相同标题共享请求与缓存，译文缓存最多 1000 条，有效期 30 天，不进入个人备份。

**密钥仅在当前 Edge 本机保存**，不随课题组配置、个人备份或 GitHub 分发。每位同门独立配置、授权并承担自己所选服务的额度或费用。缓存和密钥不会随 Zotero 账号同步。未安装沉浸式翻译或 OneScholar 时也可以使用。

当前识别参考文献区域内明确标记的标题、引号内的标题及标题链接，支持 Outlier Analysis、Random forests 等短标题，排除出版社、摘要等功能链接。已在 ScienceDirect 实测，并覆盖 IEEE 等常见引用结构。网站未单独标记标题且引用文本无明确边界时会跳过，避免把作者、期刊一并翻译。网页改版或异步加载结构变化可能需要补充适配。翻译结果供阅读参考，不修改原始引用内容，也不自动写入 Zotero 笔记或 PDF。

### Scopus 结果列表

从 ScienceDirect 的被引列表打开 Scopus 后，在研迹侧栏勾选 **Cited by** 即可翻译结果标题，无需新配置服务或新增开关。中文显示在原标题下方，原链接、作者、期刊与年份保持不变。

支持当前 Scopus 结果列表中指向 `/pages/publications/` 的文献标题；翻页、排序或列表重新渲染后，按当前可见标题继续翻译。重复出现或返回上一页的标题优先复用缓存。只处理浏览器已经正常打开的列表，不自动点击下一页或抓取全部被引结果。会话参数不会作为翻译内容发送，也不需要把带会话参数的链接分享给别人。

[阅读交互侧栏](docs/reading-workflow.png)

来源返回只记录启用本版后从 ScienceDirect 打开的 Scopus 路径，不追溯升级前已打开的结果页。原文章仍开着时直接复用，关闭后重新打开；不记录完整浏览历史。

阅读断点适用于有学术元数据或已有研迹标注的网页正文，不适用于浏览器内置 PDF 阅读器或 Scopus 结果列表。原文被沉浸式翻译隐藏时，尝试定位对应的可见译文；页面变化导致段落不能唯一匹配时，会回到接近位置并提示。

稍后读只保存标题与网页链接，不替用户导入 Zotero。阅读篮与断点保存在当前 Edge 本机，并纳入个人完整 JSON 备份；短时撤销与本次来源关系不进入备份。旧版备份仍可读取，合并时保留较新的阅读数据。

## 中英句对齐

在中文标注右侧点击“对齐”，系统会根据段落句序、长度、数字及缩写，为尚未确认的中文句子预选英文。已有确认结果保留。你可以调整勾选，或点“重新预选”；点击“保存句对”才会保存。多句中文可以共用同一句英文，也可以只对齐部分中文句子。保存后，匹配到的英文句子会一起高亮。

候选来自当前段落，按标点在本机拆句；预选只是规则推测，不确定时不勾选，关闭弹窗不会保存；**需要自己判断对应关系**，没有联网翻译或语义模型。句对写入笔记时，中文摘录仅出现一次，重复选择的英文在同一条标注中只写一次。笔记不再附加完整原文段落，也不生成 P1 等原文引用；完整原文仍留在本机供定位和重新选择。

网页应保留英文原文。翻译插件改变 DOM、重新翻译或网页改版时，优先尝试恢复摘录或英文句子；无法唯一确定句子时退回段落定位，不能保证任意网页都能逐句恢复。

## 关联 Zotero 与更新笔记

| 情况 | 操作与结果 |
| --- | --- |
| 文献已入库，网页和父文献的 DOI 一致且唯一 | 打开网页或更新笔记时自动关联；有写入授权后自动更新 |
| 文献尚未入库 | 先标注，内容缓存在当前 Edge 中 |
| 后来导入 PDF | 在 Zotero 中识别为文献父条目，确认父条目的 DOI；下次打开或刷新网页，或点击“更新笔记”时重试关联 |
| 同一 DOI 对应多篇文献 | 在侧栏选择目标文献，再更新笔记 |
| DOI 缺失或网页未识别 DOI | 展开“手动关联 / 更换文献”，按标题或关键词搜索并选择 |
| Zotero 关闭或暂时不可连接 | 保留本机标注；打开 Zotero 后刷新网页或主动更新 |

第一次写入时，Zotero 会弹出“研迹 · 网页标注”授权窗口，选择“允许”或“始终允许”。每位使用者单独授权。只允许一次时，后续写入可能再次弹窗。没有授权时自动关联不触发意外的授权弹窗，请主动点击“更新笔记”。

每个父文献使用一份带 **`研迹网页标注`** 标签的子笔记，按颜色分类整理；同一文献的不同网页入口合并更新。重复更新沿用原笔记，不新增多份。DOI 检查只在打开网页或主动操作时触发，不在后台轮询文献库。可在“偏好设置 → Zotero”关闭打开网页时自动更新。

个人总结写在笔记末尾 **“我的总结”** 下。旧版“我的总结（手写保留）”在下次成功更新时自动改为新标题，下面的手写内容保留。请保留这个分隔标题及笔记标签。手动修改上方自动摘录区时，更新会暂停；确认“重建摘录区”后，重建摘录并保留总结。检测到笔记版本在写入前改变时也会停止覆盖。

笔记采用 20 万 HTML 字符的安全预算，只写摘录、批注、已确认英文句对和手写总结，不附加整段原文。旧笔记在下次成功更新时移除自动生成的原文附录，保留同一份笔记及总结。内容超长时停止写入并保留本机数据，需先备份、整理后再更新。

## 写入 Zotero PDF 原生高亮

1. 下载 [研迹 Zotero 配套插件](dist/yanji-zotero-0.1.2.xpi)（点文件页面右侧下载按钮）。配套版本需为 0.1.2 或更新版本。在 Zotero 10 的“工具 → 插件”中点齿轮 → Install Plugin From File，选择 XPI。配套源码在 [zotero/](zotero/)。
2. 确认网页已关联到文献父条目，该条目下有已下载到本机的 PDF。
3. 中文摘录先保存对应英文句对，然后点击侧栏 **PDF 标注 → 定位英文**。直接在英文网页上的划线也可定位。
4. 只有一份 PDF 时自动选它；多份 PDF 时先自行选择。英文在 PDF 中只有一处匹配时预选；出现多处时自己选择位置，可点“查看位置”在 Zotero 中预览。没有找到的句子不写入。
5. 点击 **写入 PDF 高亮**。高亮位于 PDF 的英文句子上，颜色沿用网页分类；该高亮的评论仅保留纯文本中文摘录和个人批注，不附带来源网址或 HTML 标签。之后可在 Zotero 中查看、编辑，并随 Zotero 账号同步。

重复写入复用同源标注。更新颜色或批注时只更新研迹自己建立、且未在 Zotero 被手动改动的标注；检测到手动修改会跳过。网页删掉摘录或改变句对后，不会自动删除已写入的 PDF 标注。分类笔记和 PDF 高亮分别更新。

**自动化范围：**当前自动完成的是“已确定英文 → PDF 页码和坐标”。中文到英文仍用人工确认的句对；没有接入语义模型。按文字精确匹配，处理空白、连字和行尾断词，支持相邻两页的句子。不做 OCR；扫描版、文字提取异常、版本不同或无法唯一确定时保留待处理，不猜测写入。

只在点击时解析所选 PDF，不扫描整个文献库，不向外部发送正文。复用 Zotero 自己的阅读器，可能打开或复用一个 PDF 标签页；资源占用随该 PDF 大小变化。配套插件的版本检查由 Zotero 按普通插件更新流程访问本仓库，不上传阅读内容。

这是 Zotero 的原生标注数据，未直接把高亮烧录进 PDF 文件字节；要分享带标注的 PDF，可在 Zotero 中导出带注释的副本。配套插件使用 Zotero 10.0 的阅读器接口，后续大版本需重新验证。

PDF 标注不再生成“研迹PDF标注”和“研迹句对:…”系统标签；原有 Challenge 等分类标签和其他手动标签保留。识别关系保存在本机内部索引，并随个人完整备份迁移。换设备时先导出最新完整备份，导入后重新关联文献；Zotero 账号继续同步高亮和批注本身。

## 只标术语或短语

直接在英文原文选择单词或短语，可以按这些文字定位 PDF，不要求整句。同一词出现多处时需选择位置。若选择的是中文术语，当前规则仅提供所在英文句子的候选，不能保证该中文词对应哪几个英文词；确认后仍会高亮所选英文整句。目前未提供中文术语与英文短语的手动配对，可先在英文原文标出对应词语，实现精确到词的高亮。

## 颜色与课题组配置

在“偏好设置 → 颜色分类”修改名称、含义、颜色和顺序；分类被已有标注使用时，需先调整标注归类才能删除它。阅读设置中可选择荧光笔、下划线或两者组合，并实时预览。

**给同门使用：**分享仓库链接和 [`config/课题组配置.json`](config/课题组配置.json)。需要 PDF 高亮的同门还需各自安装配套 XPI。每人独立安装后，在“偏好设置 → 配置与备份 → 导入配置”选择该文件，再打开自己的 Zotero 并授权。统一配置包含颜色、分类和操作偏好，不含个人标注、文献关联或授权。修改后先保存偏好，再“导出配置”即可分享新版配置。

**个人完整备份**另行导出，用于迁移或恢复，包含阅读标注、文献关联、稍后读和阅读位置，不含授权密钥。不要把它当作课题组配置公开上传。导入按标注标识合并，刷新文章页后恢复高亮；备份包含 PDF 高亮内部关联，但不含笔记覆盖基线，导入后首次更新已有 Zotero 笔记可能需要确认重建摘录区。

## 数据、运行成本与使用范围

- 标注和网页定位数据保存在当前 Edge 用户配置中。写入后的文本笔记由 Zotero 账号自行同步；网页划线缓存不会随 Zotero 自动同步。
- 无自建服务器、遥测或本地 AI 模型；标注功能本身无按次调用费用。独立翻译及 Zotero 账号的额度、费用由各自服务决定。
- 标注同步请求发往本机 `http://127.0.0.1:23119/api/`；参考文献翻译仅向选中的服务发送标题，按需请求对应服务的站点权限。`tabs` 用于识别当前文章；`storage` / `unlimitedStorage` 保存本地标注；`sidePanel` 显示侧栏；`clipboardWrite` 供主动复制；HTTP/HTTPS 正文脚本用于划线和定位。
- 文章列表和标注每页 50 条，原文及编辑框按需加载；更新笔记按父文献索引读取相关文章。内存仍会随当前文章、打开的标签页和标注量变化，备份导入时解析大文件会临时占用额外内存。
- 当前范围为顶层 HTML 正文及 Zotero“我的文献库”。不支持图片划线、浏览器内置 PDF 阅读器和群组文献库。DOI 先关联识别出的父文献；PDF 标注操作再选择其 PDF 附件。

## 常见问题

**选中正文没有浮窗？**刷新安装前已打开的文章页；检查研迹是否启用。浏览器设置页、扩展商店和内置 PDF 阅读器不能注入正文脚本。多个标注扩展同时弹出时，可在当前页暂停另一个扩展。

**找不到 Zotero？**确认 Zotero 10 正在运行，并启用本地通信选项。如果 Edge 关闭了本机地址访问权限，点击侧栏 Zotero 右侧“检查连接”，允许访问 127.0.0.1。研迹使用本机 API，不使用远程账号 API。

**导入 PDF 后仍显示待入库？**确认已识别为父文献，DOI 在父文献的 DOI 字段中，且与网页一致；仅放入一个未识别的 PDF 附件不会自动匹配。

**更新时出现多份研迹笔记或缺少总结标题？**先在 Zotero 中检查笔记归属、标签和“我的总结”标题；扩展会停止自动覆盖，避免选择错误的笔记。

**换电脑怎么办？**先导出个人完整备份，在新电脑安装后导入，再单独授权 Zotero。迁移后文献关联若失效，请按 DOI 重新关联。卸载扩展前务必备份。

## 开发与验证

直接修改 `yanji-edge/` 中的 HTML、CSS、JavaScript，再在 Edge 扩展页重新加载。没有打包或依赖安装步骤。Node.js 可运行不连接 Zotero、不写个人数据的核心检查：

```sh
node tests/shared.test.cjs
node tests/reading-store.test.cjs
node tests/reference-service.test.cjs
node tests/sentence-rules.test.cjs
node tests/pdf-core.test.cjs
node tests/pdf-sync.test.cjs
node tests/pdf-links-backup.test.cjs
node tests/host-access.test.cjs
```

检查覆盖大小写颜色的真实写入协议、规则预选、颜色配置、URL/DOI 归一化、文件夹命名字符与保留名、HTML 转义、句对去重、部分对齐的长段落处理、旧总结标题迁移、原文附录移除和笔记长度保护。发布前另在隔离 Edge 环境验证了句对操作、长段落查看、重复更新、总结保留及冲突保护；真实 Zotero 写入结果不包含在公开仓库中。

PDF 联调已在 Zotero 10.0.6 的临时 PDF 副本完成：真实 Edge 写入、中文评论、分类颜色、同一高亮的批注更新及重复更新不新增标注。正式 PDF 的原有标注未修改；个人测试记录不在公开仓库中。
