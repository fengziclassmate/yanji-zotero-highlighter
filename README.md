# 研迹 · Zotero 网页标注

在 Edge 网页正文中标注中文译文，用自己的颜色分类阅读内容，再更新到 Zotero 10 对应文献的一份笔记中。

**当前版本：0.3.1。** 原生 Manifest V3 扩展，无构建步骤、第三方运行时依赖或自建服务器。无需安装额外的 Zotero 插件，也无需填写 Zotero 账号密码或手动申请 API Key。

## 安装到 Edge

1. 在本仓库点击 **Code → Download ZIP**，完整解压到固定位置。
2. Edge 地址栏输入 `edge://extensions/`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择仓库中的 **`yanji-edge` 文件夹**，该文件夹内应有 `manifest.json`。
4. 将“研迹”固定到工具栏，刷新已经打开的文章页，点击图标打开侧栏。
5. 打开 Zotero 10，在“设置 → 高级”中启用“允许此计算机上的其他应用程序与 Zotero 通信”，并保持 Zotero 运行。

本地 HTML 需要在扩展详情中开启“允许访问文件 URL”。普通期刊网页不需要这一步。

**升级：**先在研迹“配置与备份”导出个人完整备份，再覆盖原安装位置中的文件。在 Edge 扩展管理页点击研迹的“重新加载”，最后刷新文章页。保持安装路径不变，避免卸载后重新安装造成数据丢失。

## 阅读与标注

1. 在期刊的 HTML 正文中阅读，可先用沉浸式翻译显示中英双语。
2. 选中中文或英文，点击浮窗中的颜色分类保存。气泡图标添加批注，叠页图标复制，右上角 × 关闭。
3. 点击已有划线可编辑分类和批注；`Ctrl / Cmd + Enter` 保存。
4. 侧栏显示摘录、分类和批注。标题右下角、DOI 旁和摘录右下角的复制按钮各自复制相应内容。定位按钮返回网页段落。
5. 未做句对时，“原文段落”按需打开共用查看窗；做了句对后，卡片只展开对应英文，不再重复铺开长段落。“完整段落”仍可查看定位原文。

浮窗支持拖动右下角调整大小并记忆。背景透明度、按钮大小、全部分类展开、快捷键和默认标注方式可在偏好设置中调整。侧栏和偏好设置分别支持 `Ctrl + 滚轮` 缩放并记忆；点击比例或按 `Ctrl + 0` 恢复 100%。偏好页根据窗口可用宽度重新布局。

## 中英句对齐

在中文标注右侧点击“对齐”，选择一句中文，再勾选对应的一句或多句英文，点击“保存句对”。多句中文可以共用同一句英文，也可以只对齐部分中文句子。保存后，匹配到的英文句子会一起高亮。

候选来自当前段落，按标点在本机拆句；**需要自己判断对应关系**，没有联网翻译或语义模型。句对写入笔记时，中文摘录仅出现一次，重复选择的英文在同一条标注中只写一次。已对齐的片段不再附加整段英文；完整原文仍留在本机供定位和重新选择。

网页应保留英文原文。翻译插件改变 DOM、重新翻译或网页改版时，优先尝试恢复摘录或英文句子；无法唯一确定句子时退回段落定位，不能保证任意网页都能逐句恢复。

## 关联 Zotero 与更新笔记

| 情况 | 操作与结果 |
| --- | --- |
| 文献已入库，网页和父文献的 DOI 一致且唯一 | 打开网页或更新笔记时自动关联；有写入授权后自动更新 |
| 文献尚未入库 | 先标注，内容缓存在当前 Edge 中 |
| 后来导入 PDF | 在 Zotero 中识别为文献父条目，确认父条目的 DOI；下次打开或刷新网页，或点击“更新笔记”时重试关联 |
| 同一 DOI 对应多篇文献 | 在侧栏选择目标文献，再更新笔记 |
| DOI 缺失或网页未识别 DOI | 展开“手动关联 / 更换文献”，按标题或关键词搜索并选择 |
| Zotero 关闭或暂时不可连接 | 保留本机标注；打开 Zotero 后刷新网页或主动更新 |

第一次写入时，Zotero 会弹出“研迹 · 网页标注”授权窗口，选择“允许”或“始终允许”。每位使用者单独授权。只允许一次时，后续写入可能再次弹窗。没有授权时自动关联不触发意外的授权弹窗，请主动点击“更新笔记”。

每个父文献使用一份带 **`研迹网页标注`** 标签的子笔记，按颜色分类整理；同一文献的不同网页入口合并更新。重复更新沿用原笔记，不新增多份。DOI 检查只在打开网页或主动操作时触发，不在后台轮询文献库。可在“偏好设置 → Zotero”关闭打开网页时自动更新。

个人总结写在笔记末尾 **“我的总结”** 下。旧版“我的总结（手写保留）”在下次成功更新时自动改为新标题，下面的手写内容保留。请保留这个分隔标题及笔记标签。手动修改上方自动摘录区时，更新会暂停；确认“重建摘录区”后，重建摘录并保留总结。检测到笔记版本在写入前改变时也会停止覆盖。

笔记采用 20 万 HTML 字符的安全预算。未对齐的英文原段落按内容去重，过长时只精简可选的英文段落并标明节选；中文摘录、批注、已选英文和手写总结不截断。如果必留内容本身超长，会停止写入并保留本机数据，需先备份、整理后再更新。

## 颜色与课题组配置

默认沿用九类颜色，分类含义留空，由使用者自行定义：

| 分类 | 默认颜色 |
| --- | --- |
| Content | `#ffd400` |
| Challenge | `#7BC289` |
| Cons | `#2ea8e5` |
| Worth | `#f19837` |
| Cite_Useful | `#e56eee` |
| Terms | `#a28ae5` |
| Jot | `#aaaaaa` |
| Unclear | `#ff6666` |
| Mark | `#953984` |

在“偏好设置 → 颜色分类”修改名称、含义、颜色和顺序；分类被已有标注使用时，需先调整标注归类才能删除它。阅读设置中可选择荧光笔、下划线或两者组合，并实时预览。

**给同门使用：**分享仓库链接和 [`config/课题组配置.json`](config/课题组配置.json)。每人独立安装后，在“偏好设置 → 配置与备份 → 导入配置”选择该文件，再打开自己的 Zotero 并授权。统一配置包含颜色、分类和操作偏好，不含个人标注、文献关联或授权。修改后先保存偏好，再“导出配置”即可分享新版配置。

**个人完整备份**另行导出，用于迁移或恢复，包含阅读标注和文献关联，不含授权密钥。不要把它当作课题组配置公开上传。导入按标注标识合并，刷新文章页后恢复高亮；备份不含笔记覆盖基线，导入后首次更新已有 Zotero 笔记可能需要确认重建摘录区。

## 数据、运行成本与使用范围

- 标注和网页定位数据保存在当前 Edge 用户配置中。写入后的文本笔记由 Zotero 账号自行同步；网页划线缓存不会随 Zotero 自动同步。
- 无自建服务器、付费接口、遥测或本地 AI 模型；扩展本身无按次调用费用。Zotero 账号及其他翻译插件的费用由各自服务决定。
- 扩展的数据请求仅发往本机 `http://127.0.0.1:23119/api/`。`tabs` 用于识别当前文章；`storage` / `unlimitedStorage` 保存本地标注；`sidePanel` 显示侧栏；`clipboardWrite` 供主动复制；HTTP/HTTPS 正文脚本用于划线和定位。
- 文章列表和标注每页 50 条，原文及编辑框按需加载；更新笔记按父文献索引读取相关文章。内存仍会随当前文章、打开的标签页和标注量变化，备份导入时解析大文件会临时占用额外内存。
- 当前范围为顶层 HTML 正文及 Zotero“我的文献库”。不支持图片划线、浏览器内置 PDF 阅读器和群组文献库。PDF 导入后关联的是识别出的父文献条目，不是直接向 PDF 附件写注释。

## 常见问题

**选中正文没有浮窗？**刷新安装前已打开的文章页；检查研迹是否启用。浏览器设置页、扩展商店和内置 PDF 阅读器不能注入正文脚本。多个标注扩展同时弹出时，可在当前页暂停另一个扩展。

**找不到 Zotero？**确认 Zotero 10 正在运行，并启用本地通信选项。研迹使用本机 API，不使用远程账号 API。

**导入 PDF 后仍显示待入库？**确认已识别为父文献，DOI 在父文献的 DOI 字段中，且与网页一致；仅放入一个未识别的 PDF 附件不会自动匹配。

**更新时出现多份研迹笔记或缺少总结标题？**先在 Zotero 中检查笔记归属、标签和“我的总结”标题；扩展会停止自动覆盖，避免选择错误的笔记。

**换电脑怎么办？**先导出个人完整备份，在新电脑安装后导入，再单独授权 Zotero。迁移后文献关联若失效，请按 DOI 重新关联。卸载扩展前务必备份。

## 开发与验证

直接修改 `yanji-edge/` 中的 HTML、CSS、JavaScript，再在 Edge 扩展页重新加载。没有打包或依赖安装步骤。Node.js 可运行不连接 Zotero、不写个人数据的核心检查：

```sh
node tests/shared.test.cjs
```

检查覆盖颜色配置、URL/DOI 归一化、HTML 转义、句对去重、部分对齐的长段落处理、旧总结标题迁移、原文去重和笔记长度保护。发布前另在隔离 Edge 环境验证了句对操作、长段落查看、重复更新、总结保留及冲突保护；真实 Zotero 写入结果不包含在公开仓库中。
