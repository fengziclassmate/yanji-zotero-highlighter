# 研迹 · Zotero 网页标注

在 Edge 网页正文中标注中文译文，用自己的颜色分类阅读内容，再更新到 Zotero 10 对应文献的一份笔记中。

**当前版本：0.13.0。** 原生 Manifest V3 扩展，无构建步骤、第三方运行时依赖或自建服务器。网页标注和分类笔记无需额外的 Zotero 插件；要显示 Zotero PDF 原生高亮或将网页 PDF 保存至本地文献库，安装下方的配套插件。无需填写 Zotero 账号密码或手动申请 Zotero API Key。

## 安装到 Edge

1. 在本仓库点击 **Code → Download ZIP**，完整解压到固定位置。
2. Edge 地址栏输入 `edge://extensions/`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择仓库中的 **`yanji-edge` 文件夹**，该文件夹内应有 `manifest.json`。
4. 将“研迹”固定到工具栏，刷新已经打开的文章页，点击图标打开侧栏。
5. 打开 Zotero 10，在“设置 → 高级”中启用“允许此计算机上的其他应用程序与 Zotero 通信”，并保持 Zotero 运行。

本地 HTML 需要在扩展详情中开启“允许访问文件 URL”。普通期刊网页不需要这一步。

**升级：**先在研迹“配置与备份”导出个人完整备份，再覆盖原安装位置中的文件。在 Edge 扩展管理页点击研迹的“重新加载”，最后刷新文章页。保持安装路径不变，避免卸载后重新安装造成数据丢失。


## 网页 PDF 保存与命名

Edge 扩展 0.13.0 配合 Zotero 插件 0.5.1，侧栏“PDF 标注”旁的下载图标打开保存小窗。

1. 首次在小窗点击文件夹图标，选择自己的本地文献库根目录。保持 Zotero 运行；首次保存按 Edge 提示允许下载权限。
2. 研迹优先复用该期刊手动确认过的目录与简称，再按当前文献附件的位置、期刊全名/简称、目录名和已有文件名匹配。例如 Remote Sensing 可选到对应目录，并沿用文件名中的 RS。需要时只查询该期刊少量已有条目的文件位置；匹配不唯一时保留选择，不自动放到根目录。仅在打开保存窗时核对目录，最多显示三层文件夹，读取少量文件名，不扫描 PDF 正文或持续查询文献库。
3. 阅读进度、重要程度、阅读优先级和发布状态分别选择，前缀按“重要程度-优先级-阅读进度-发布状态”组合，例如 `SS-P1-R-G`。常规程度与未发布默认省略，未读为 `T`。日期支持年份、年月或年月日；选择 Accept 时附加 `a`，Publish 不附加。只预填网页明确提供的日期，缺失时手动填写。
4. 填写中文关键词，预览并按需编辑完整文件名，例如 `SS-P1-R-G_20261106a_SCS_（城市热环境）Urban form and heat exposure.pdf`。文件名中的 Windows 禁用字符转为空格；超长文件名会提示缩短，不自动截掉标题。
5. 点击“保存 PDF”。浏览器下载完成后，Zotero 配套插件校验 PDF 格式并保存到所选目录；已关联文献时可同时创建链接附件，随后可沿用研迹 PDF 句对标注。未入库或 DOI 匹配不唯一时可以仅保存文件，不自动新建文献；若需立即关联，先在侧栏选择对应文献。

同名文件不覆盖；同一路径已经是对应文献的 PDF 附件时直接沿用。下载数据走浏览器文件下载，不将整份 PDF 编码后存入扩展；只监听研迹自身任务的完成状态，不在后台扫描文献库。异常下载会显示错误，登录或验证页不会被当成 PDF 入库。Edge 若启用了逐次下载询问，请在浏览器下载提示中点击“保存”，之后研迹才会移入文献库；研迹不修改浏览器的全局下载偏好。中转文件以可读名称放在“研迹临时”的独立任务子目录中；超长中转名会适当缩短，文献库中的正式名称不截断。转存确认成功后，研迹清理中转文件、空任务目录及自身对应的成功下载记录，不清理其他下载或失败记录；这样不会留下随机文件名和“已删除”的中转条目。下载中断、Zotero 退出或重启时，未完成的中转文件可在“研迹临时”中恢复。

未启用自动入库时，原关联功能使用 Zotero **链接附件**：文献条目及 PDF 标注继续由 Zotero 账号同步，PDF 文件本身须使用自己的文件夹同步方式。Zotero Storage/WebDAV 不同步链接文件。各设备可配置 Zotero 的链接附件基准目录。启用下方自动入库后，新导入 PDF 使用存储副本。下载根目录、期刊目录映射保存在本机 Zotero 设置中，不随课题组配置或研迹备份分发；每位同门需选择自己的目录。

ScienceDirect 下载会按需打开网页的 PDF 入口，等待页面加载完成；遇到验证页时立即显示，需本人完成验证。成功归档后，只关闭研迹创建且仍在后台的临时 PDF 页；当前阅读页和原先已打开的 PDF 页保留。签名地址过期时重新获取；其他文章的链接会被拒绝。Edge 冻结文章标签时先激活，网页超过 10 秒不响应会提示刷新。保存窗显示当前处理阶段。

**Windows 上直接通过 Edge 阅读器保存（配套插件 0.4.1）：**

点击研迹 **保存 PDF**，研迹自动找到同篇文献的阅读器、调用其保存按钮并填写临时保存位置，随后按原来的命名和期刊目录归档；勾选自动入库时继续加入 Zotero。已有 PDF 签名地址即使过期，也优先使用已经加载的阅读器，避免独立重新请求被网站验证拦截。成功结果会记住，重复保存沿用已有文献及附件。

支持当前 Edge 默认阅读器与 Adobe 阅读器的保存控件。按 PDF 地址、窗口和保存对话框逐步核对；页面已变更或无法唯一识别时停止。Windows 助手由 Zotero 在这次保存期间隐藏启动，最长 60 秒，无常驻服务，不修改浏览器默认下载设置。辅助脚本随 XPI 提供，使用 Windows 自带 PowerShell 和 UI Automation；URL 与文件路径通过 JSON 数据文件传入，不拼接为命令。实际 PDF 数据由阅读器写入磁盘，前端不缓存或编码整份 PDF。

其他系统继续使用网页下载和下面的手动选择入口。网站要求登录或人机验证时，仍需本人完成。首次更新后已打开的 ScienceDirect PDF 可以继续保存，无需刷新过期地址。

**无法使用自动保存的阅读器，可选择本地文件：**

1. 点击 PDF 阅读器自身的下载图标，把已加载的 PDF 保存到本机。
2. 在研迹保存窗点击 **选择已下载 PDF**，在 Zotero 弹出的系统文件选择器中选中该文件。需要配套插件 0.3.2。
3. 继续沿用保存窗中的期刊目录、文件名和自动入库开关。研迹校验 PDF 文件头、避免覆盖不同内容的同名文件，保留所选原文件。重复提交沿用同一结果，不重复创建条目或附件。

文件选择使用独立的任务状态返回，避免等待对话框时把浏览器请求超时报成 Zotero 离线。只在这次操作期间查询自身任务状态，最长 10 分钟，不扫描文献库。ScienceDirect 的 PDF 标签页沿用同一窗口中对应正文的标题、DOI 和保存设置。网页未提供作者时，先导入独立 PDF 附件，交由 Zotero 识别元数据，避免直接创建缺少作者的文献；识别结果在 Zotero 查看。

SAGE 的在线阅读页是 HTML；研迹会先打开同一 DOI 的真实 PDF，再调用 Edge 阅读器保存，不将网页当成 PDF。此前保存窗残留的 reader 链接也会自动转换。

当前识别网页元数据中的 PDF 地址及正文区域的 PDF 下载链接；未识别时可在小窗粘贴 PDF 链接。需要网站允许当前浏览器访问全文，部分登录页、验证页或嵌套阅读器需要先在网站打开真实 PDF；不保证所有出版社页面通用。

### 下载后自动加入 Zotero

1. 在偏好设置 → **Zotero** 勾选 **下载 PDF 后自动入库**；开关立即保存。未关联文献时，保存窗的 **自动加入 Zotero 文库** 也控制同一偏好。新功能默认关闭，每位用户单独启用，不随课题组配置或完整备份分发。
2. 只处理研迹下载的这一份 PDF，不监听整个文件夹，不调用旧批处理工具，也不重启 Zotero。原有的“关联到 Zotero 文献”选项保留；自动入库关闭时，仍可按原选项附加链接文件。
3. 启用后，源目录的规范命名 PDF 保留，新增 PDF 作为 **存储副本**加入“我的文库”，可按 Zotero Storage/WebDAV 等现有文件同步设置同步。已存在的同内容附件直接复用，不自动转换或覆盖原附件。
4. 优先用当前网页的标题、DOI、作者、期刊、日期等题录建条目，不用文件名里的阅读状态或中文关键词充当题名。按 DOI、来源地址、规范化标题及已知 PDF 内容摘要查重；不遍历读取整库 PDF 内容。
5. 匹配多条文献时不自动合并：可先在侧栏选择；后续才发现歧义时保留独立 PDF 附件并提示在 Zotero 确认归属。网页题录不足时，保留独立 PDF，并遵循 Zotero 自己的自动识别设置。原批量同步工具仍可用于其他方式保存的文件，其内容哈希检查可识别已入库的副本。
6. 新文献入库后会关联当前网页；已有缓存标注继续按原自动更新偏好整理到同一份文献笔记。刚才仅保存的文件也可在同一保存窗口勾选后加入 Zotero，复用已保存文件。

这是文件导入与题录关联，不是源目录和 Zotero 存储目录之间的双向文件同步。不同内容的 PDF 版本可作为同一文献下的新附件保留，避免覆盖已有修改。

### PDF 平台适配

| 平台 | 处理方式 |
| --- | --- |
| IEEE Xplore | 识别 stamp 阅读器入口，使用 getPDF 文件接口；补充页面 JSON 中的期刊和公开日期 |
| SAGE Journals | 将同一 DOI 的 epub、reader、epdf 和正文入口转换为实际 PDF；过滤其他 DOI，保留访问参数，使用 Edge 阅读器自动保存 |
| Taylor & Francis | 识别当前 DOI 的 ePDF/PDF 入口，采用 PDF 文件地址 |
| MDPI | 采用当前文章的 /pdf 或文章文件，排除期刊 flyer 等宣传资料 |
| Nature | 优先使用网页实际 Download PDF 按钮；支持部分文章的 _reference.pdf 下载入口，避免元数据中的通用 .pdf 地址转回正文 |
| Copernicus / ESSD | 只选择当前文章的主文 PDF，不混入其他文章链接 |
| OpenReview | 识别 /pdf?id= 及主文 PDF 附件，排除其他评论附件 |

上述六个平台均在测试浏览器当前具备的访问权限下完成真实 PDF 下载和文件头校验。文件仍沿用阅读状态、日期类型、期刊简称、中文关键词及原文标题的命名流程。IEEE 和 Taylor 不再把阅读器网页当成 PDF 文件下载。

下载权限由网站决定；需要登录、机构访问或人机验证时，应先在网站完成；研迹不会把验证页标题预填为论文名。研迹只在操作时读取当前页面的下载入口，不轮询文献库，也不增加后台翻译请求。

入口核对参考：[Zotero 官方翻译器项目](https://github.com/zotero/translators)。研迹独立实现，未引入其代码或运行时依赖。

## 阅读与标注

1. 在期刊的 HTML 正文中阅读，可先用沉浸式翻译显示中英双语。
2. 选中中文或英文，点击浮窗中的颜色分类保存。气泡图标添加批注，叠页图标复制，右上角 × 关闭。
3. 点击已有划线可编辑分类和批注；`Ctrl / Cmd + Enter` 保存。
4. 侧栏显示摘录、分类和批注。标题右下角有两个纯图标按钮，分别用复制图标复制完整标题、文件夹图标复制安全文件夹名；悬停可查看提示；后者将 Windows 禁用字符 `\ / : * ? " < > |` 与控制字符替换为空格，合并空白、去掉结尾的句点和空格，保留中文全角标点。CON、NUL 等系统保留名会添加 `_` 前缀，空名称使用“未命名”。不自动截断长标题，实际长度仍受系统和所在路径限制。DOI 旁和摘录右下角的按钮各自复制相应内容。定位按钮返回网页段落。
5. 未做句对时，“原文段落”按需打开共用查看窗；做了句对后，卡片只展开对应英文，不再重复铺开长段落。“完整段落”仍可查看定位原文。

批注浮窗可拖动标题栏调整位置，并在本机记忆；分类直接点击颜色标签选择，摘录左侧色带同步显示当前分类颜色。批注输入框默认更紧凑，可继续手动拉高。浮窗支持拖动右下角调整大小并记忆。背景透明度、按钮大小、全部分类展开、快捷键和默认标注方式可在偏好设置中调整。侧栏和偏好设置分别支持 `Ctrl + 滚轮` 缩放并记忆；点击比例或按 `Ctrl + 0` 恢复 100%。偏好页根据窗口可用宽度重新布局。

## 文献标题翻译

1. 点击研迹右上角偏好设置，打开独立设置弹窗，选择 **翻译**。重复点击会聚焦已有窗口，不新增标签页。拖动调整窗口大小或位置会自动在本机记忆，下次打开恢复；换到较小屏幕时保持在当前屏幕可见范围内。
2. 选择翻译服务，填写自己的 API Key；Azure 区域按资源所在地填写，全球资源可留空。各服务的配置分别在本机保留。
3. 点击 **测试翻译**，按浏览器提示允许访问该服务；成功后在文章侧栏按需勾选 **参考文献翻译**、**推荐文章**、**Cited by**，三项并列显示，独立控制。
4. 滚动到相应区域，研迹保留原始英文，为已勾选类别添加中文标题。作者、期刊、年份、DOI 和其他插件的标签保留。推荐文章和 Cited by 支持 ScienceDirect 卡片；从被引区域跳转到 Scopus 文献结果列表后，继续沿用 **Cited by** 勾选项。网站未加载的文章和未打开的结果页不会主动请求加载。
5. 取消某一项，只移除该类别的研迹译文并停止它的后续请求；其他已勾选类别保留。重新勾选优先使用已有缓存，同一标题跨类别共用缓存。

| 服务 | 配置 |
| --- | --- |
| 小牛翻译 | 自己的小牛 API Key，调用官方文本翻译 API |
| Google 翻译（免 Key，实验） | 无需 Key，使用网页接口；依赖网络可达性，可能限流或失效 |
| 微软 Edge（免 Key，实验） | 无需 Key，使用网页接口；可能限流或失效 |
| Google Cloud | 自己的 Cloud Translation Basic v2 API Key |
| 微软 Azure | 自己的 Translator Key 和区域；支持免费层，额度以服务商规则为准 |

新安装时三项默认关闭；升级时保留原参考文献开关，新两项默认关闭，选择状态在本机记忆。只发送识别出的标题，不发送整篇正文、作者列表或 Zotero 文献库。标题进入阅读区域附近时才请求翻译，切到后台后暂停新任务；全局串行发送，间隔至少 600ms。相同标题共享请求与缓存，译文缓存最多 1000 条，有效期 30 天，不进入个人备份。

**密钥仅在当前 Edge 本机保存**，不随课题组配置、个人备份或 GitHub 分发。每位同门独立配置、授权并承担自己所选服务的额度或费用。缓存和密钥不会随 Zotero 账号同步。未安装沉浸式翻译或 OneScholar 时也可以使用。

当前识别参考文献区域内明确标记的标题、引号内的标题及标题链接，支持 Outlier Analysis、Random forests 等短标题，排除出版社、摘要等功能链接。已在 ScienceDirect 实测，并覆盖 IEEE 等常见引用结构。网站未单独标记标题且引用文本无明确边界时会跳过，避免把作者、期刊一并翻译。网页改版或异步加载结构变化可能需要补充适配。翻译结果供阅读参考，不修改原始引用内容，也不自动写入 Zotero 笔记或 PDF。

### Scopus 结果列表

从 ScienceDirect 的被引列表打开 Scopus 后，在研迹侧栏勾选 **Cited by** 即可翻译结果标题，无需新配置服务或新增开关。中文显示在原标题下方，原链接、作者、期刊与年份保持不变。

支持当前 Scopus 结果列表中指向 `/pages/publications/` 的文献标题；翻页、排序或列表重新渲染后，按当前可见标题继续翻译。重复出现或返回上一页的标题优先复用缓存。只处理浏览器已经正常打开的列表，不自动点击下一页或抓取全部被引结果。会话参数不会作为翻译内容发送，也不需要把带会话参数的链接分享给别人。

标注数量左侧的箭头可折叠整个标注区域，每篇文章分别记忆本机状态；重开侧栏或返回文章时恢复。卡片操作已合并为紧凑行，长摘录与批注只收紧显示，不改变保存、复制及同步的全文。

## 中英句对齐

在中文标注右侧点击“对齐”，系统会根据段落句序、长度、数字及缩写，为尚未确认的中文句子预选英文。已有确认结果保留。你可以调整勾选，或点“重新预选”；点击“保存句对”才会保存。多句中文可以共用同一句英文，也可以只对齐部分中文句子。保存后，匹配到的英文句子会一起高亮。

候选来自当前段落，按标点在本机拆句；预选只是规则推测，不确定时不勾选，关闭弹窗不会保存；**需要自己判断对应关系**，没有联网翻译或语义模型。句对写入笔记时，中文摘录仅出现一次，重复选择的英文在同一条标注中只写一次。笔记不再附加完整原文段落，也不生成 P1 等原文引用；完整原文仍留在本机供定位和重新选择。

网页应保留英文原文。翻译插件改变 DOM、重新翻译或网页改版时，优先尝试恢复摘录或英文句子；无法唯一确定句子时退回段落定位，不能保证任意网页都能逐句恢复。

## 关联 Zotero 与更新笔记

| 情况 | 操作与结果 |
| --- | --- |
| 文献已入库，网页和父文献的 DOI 一致且唯一 | 打开网页或更新笔记时自动关联；有写入授权后自动更新 |
| 文献尚未入库 | 先标注，内容缓存在当前 Edge 中 |
| 后来导入 PDF | 在 Zotero 中识别为文献父条目，确认父条目的 DOI；下次打开或刷新网页，或点击“更新笔记”时重试关联 |
| 同一 DOI 对应多篇文献 | 在侧栏选择目标文献，再更新笔记 |
| DOI 缺失或网页未识别 DOI | 展开“手动关联 / 更换文献”，按标题或关键词搜索并选择 |
| Zotero 关闭或暂时不可连接 | 保留本机标注；打开 Zotero 后刷新网页或主动更新 |

第一次写入时，Zotero 会弹出“研迹 · 网页标注”授权窗口，选择“允许”或“始终允许”。每位使用者单独授权。只允许一次时，后续写入可能再次弹窗。没有授权时自动关联不触发意外的授权弹窗，请主动点击“更新笔记”。

每个父文献使用一份带 **`研迹网页标注`** 标签的子笔记，按颜色分类整理；同一文献的不同网页入口合并更新。重复更新沿用原笔记，不新增多份。DOI 检查只在打开网页或主动操作时触发，不在后台轮询文献库。可在“偏好设置 → Zotero”关闭打开网页时自动更新。

个人总结写在笔记末尾 **“我的总结”** 下。旧版“我的总结（手写保留）”在下次成功更新时自动改为新标题，下面的手写内容保留。请保留这个分隔标题及笔记标签。手动修改上方自动摘录区时，更新会暂停；确认“重建摘录区”后，重建摘录并保留总结。检测到笔记版本在写入前改变时也会停止覆盖。

笔记采用 20 万 HTML 字符的安全预算，只写摘录、批注、已确认英文句对和手写总结，不附加整段原文。旧笔记在下次成功更新时移除自动生成的原文附录，保留同一份笔记及总结。内容超长时停止写入并保留本机数据，需先备份、整理后再更新。

## 写入 Zotero PDF 原生高亮

1. 下载 [研迹 Zotero 配套插件](dist/yanji-zotero-0.5.1.xpi)（点文件页面右侧下载按钮）。配套版本需为 0.1.2 或更新版本。在 Zotero 10 的“工具 → 插件”中点齿轮 → Install Plugin From File，选择 XPI。配套源码在 [zotero/](zotero/)。
2. 确认网页已关联到文献父条目，该条目下有已下载到本机的 PDF。
3. 中文摘录先保存对应英文句对，然后点击侧栏 **PDF 标注 → 定位英文**。直接在英文网页上的划线也可定位。
4. 只有一份 PDF 时自动选它；多份 PDF 时先自行选择。英文在 PDF 中只有一处匹配时预选；出现多处时自己选择位置，可点“查看位置”在 Zotero 中预览。没有找到的句子不写入。
5. 点击 **写入 PDF 高亮**。高亮位于 PDF 的英文句子上，颜色沿用网页分类；该高亮的评论仅保留纯文本中文摘录和个人批注，不附带来源网址或 HTML 标签。之后可在 Zotero 中查看、编辑，并随 Zotero 账号同步。

重复写入复用同源标注。更新颜色或批注时只更新研迹自己建立、且未在 Zotero 被手动改动的标注；检测到手动修改会跳过。网页删掉摘录或改变句对后，不会自动删除已写入的 PDF 标注。分类笔记和 PDF 高亮分别更新。

**自动化范围：**当前自动完成的是“已确定英文 → PDF 页码和坐标”。中文到英文仍用人工确认的句对；没有接入语义模型。按文字精确匹配，处理空白、连字和行尾断词，支持相邻两页的句子。不做 OCR；扫描版、文字提取异常、版本不同或无法唯一确定时保留待处理，不猜测写入。

只在点击时解析所选 PDF，不扫描整个文献库，不向外部发送正文。复用 Zotero 自己的阅读器，可能打开或复用一个 PDF 标签页；资源占用随该 PDF 大小变化。配套插件的版本检查由 Zotero 按普通插件更新流程访问本仓库，不上传阅读内容。

这是 Zotero 的原生标注数据，未直接把高亮烧录进 PDF 文件字节；要分享带标注的 PDF，可在 Zotero 中导出带注释的副本。配套插件使用 Zotero 10.0 的阅读器接口，后续大版本需重新验证。

PDF 标注不再生成“研迹PDF标注”和“研迹句对:…”系统标签；原有 Challenge 等分类标签和其他手动标签保留。识别关系保存在本机内部索引，并随个人完整备份迁移。换设备时先导出最新完整备份，导入后重新关联文献；Zotero 账号继续同步高亮和批注本身。

## 只标术语或短语

直接在英文原文选择单词或短语，可以按这些文字定位 PDF，不要求整句。同一词出现多处时需选择位置。若选择的是中文术语，当前规则仅提供所在英文句子的候选，不能保证该中文词对应哪几个英文词；确认后仍会高亮所选英文整句。目前未提供中文术语与英文短语的手动配对，可先在英文原文标出对应词语，实现精确到词的高亮。

## 数据、运行成本与使用范围

- 标注和网页定位数据保存在当前 Edge 用户配置中。写入后的文本笔记由 Zotero 账号自行同步；网页划线缓存不会随 Zotero 自动同步。
- 无自建服务器、遥测或本地 AI 模型；标注功能本身无按次调用费用。独立翻译及 Zotero 账号的额度、费用由各自服务决定。
- 标注同步请求发往本机 `http://127.0.0.1:23119/api/`；参考文献翻译仅向选中的服务发送标题，按需请求对应服务的站点权限。`tabs` 用于识别当前文章；`storage` / `unlimitedStorage` 保存本地标注；`sidePanel` 显示侧栏；`clipboardWrite` 供主动复制；HTTP/HTTPS 正文脚本用于划线和定位。
- 文章列表和标注每页 50 条，原文及编辑框按需加载；更新笔记按父文献索引读取相关文章。内存仍会随当前文章、打开的标签页和标注量变化，备份导入时解析大文件会临时占用额外内存。
- 当前范围为顶层 HTML 正文及 Zotero“我的文献库”。不支持图片划线、浏览器内置 PDF 阅读器和群组文献库。DOI 先关联识别出的父文献；PDF 标注操作再选择其 PDF 附件。

## 常见问题

**选中正文没有浮窗？**刷新安装前已打开的文章页；检查研迹是否启用。浏览器设置页、扩展商店和内置 PDF 阅读器不能注入正文脚本。多个标注扩展同时弹出时，可在当前页暂停另一个扩展。

**找不到 Zotero？**确认 Zotero 10 正在运行，并启用本地通信选项。如果 Edge 关闭了本机地址访问权限，点击侧栏 Zotero 右侧“检查连接”，允许访问 127.0.0.1。研迹使用本机 API，不使用远程账号 API。

**导入 PDF 后仍显示待入库？**确认已识别为父文献，DOI 在父文献的 DOI 字段中，且与网页一致；仅放入一个未识别的 PDF 附件不会自动匹配。

**更新时出现多份研迹笔记或缺少总结标题？**先在 Zotero 中检查笔记归属、标签和“我的总结”标题；扩展会停止自动覆盖，避免选择错误的笔记。

**换电脑怎么办？**先导出个人完整备份，在新电脑安装后导入，再单独授权 Zotero。迁移后文献关联若失效，请按 DOI 重新关联。卸载扩展前务必备份。

侧栏沿用原有配色和交互，使用 12/14/16 三档字号、统一圆角与间距。桌面按钮点击区至少 32px，图标为 12px；窄侧栏和放大时操作区自动换行。标题复制仍位于右下角，缩放记忆及标注折叠记忆保留。

## 接收日期与文献分类

保存窗优先选择接收日期，文件名加 a；缺少接收日期时选择在线公开日期，再回退网页出版日期。ScienceDirect 只在打开保存窗时按需展开可见的 Show more 读取文章历史，随后恢复原展开状态；Taylor & Francis 读取页面的 Received/Accepted/Published online 信息。日期和日期类型均可手动调整。网站错误或验证页不会生成虚假的日期。

文献类型根据明确的文章标签自动选择，也可在保存窗改为常规论文、综述或数据集。配套插件按现有 Survey/Review/综述、DataSource/Dataset/数据集目录分类：优先使用分类目录下匹配期刊的子目录，否则使用综合目录或分类根目录；目录不唯一时手动选择。选择分类目录不会用文件夹名覆盖期刊标符。例如综述进入 Survey 下的通用目录时仍沿用 TGRS；数据集进入 DataSource 时仍沿用 RS。分类目录的手动选择按文献类型和期刊记忆，不覆盖该期刊常规论文的保存位置。

使用这项分类功能需 Zotero 配套插件 0.5.0。目录及映射留在各用户本机，随文献库根目录变化而重置。

## 文献状态与新期刊目录

保存窗的四个状态独立选择，前缀按下表顺序组合，空标识省略：

| 维度 | 默认选项 |
| --- | --- |
| 重要程度 | 常规（省略）、S 重要、SS 核心、SSS 关键 |
| 阅读优先级 | 常规（省略）、P1 立即阅读、P2 近期阅读、P3 备用 |
| 阅读进度 | T 未读、L 略读、R 精读、H 暂缓、X 排除 |
| 发布状态 | 未发布（省略）、D 草稿、G 公众号发布 |

例如 **SS-P1-R-G_202609_AISE_（知识图谱）Example title.pdf**。各文章的选择在本机记忆；旧下载文件名中的 T/L/G、ST/SL/SG 仍可读取。已有 PDF 不会自动改名。

在“偏好设置 → Zotero → 文献状态与前缀”中自定义代码、含义及顺序，每行写“代码=含义”，空标识写为“-”。代码不使用横线或下划线，这两个符号保留给文件名结构；配置随课题组配置导出，文章选择随个人备份保存。

常规文章未匹配到已有期刊目录时，根据文章来源，在唯一匹配的出版社根目录下建议新的期刊子目录；点击保存 PDF 时才创建。支持现有 IEEE、Elsevier、MDPI、Nature、Taylor & Francis、SAGE 根目录。例如 IEEE 文章的期刊为 Artificial Intelligence Science and Engineering 时建议 IEEE/AISE，并保留 AISE 期刊标符。目录匹配有歧义、来源未知或没有对应出版社根目录时继续手动选择。综述与数据集继续沿用现有分类目录规则。

新建期刊目录需要 Zotero 配套插件 0.5.1。ESSD 读取页面的 Accepted/Published 日期，优先接收日期；IEEE 的 September 2026 等仅有年月的出版日期记录为 202609，不补写具体日，也不使用 dateOfInsertion 入站日期。
